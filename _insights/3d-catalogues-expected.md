For a long time, a 3D model of an industrial product was something you sent on request. A design engineer asked for a STEP file, a sales engineer forwarded the request to the drawing office, and a few days later a file arrived by email.

That process is becoming a disadvantage. Engineers who specify pumps, valves, motors and machinery components increasingly expect to find a 3D view and a CAD download on the product page, the same way they find a data sheet.

## Why buyers expect 3D

**Engineers design in 3D.** Plant layouts, skids and machines are designed in CAD. To place your product in their design, engineers need a model with correct dimensions and connections. The supplier who provides it immediately is the easier one to specify.

**Fewer mistakes.** A model shows the real envelope, flange positions, terminal box orientation and service clearances. Problems that would surface on site show up in the design instead.

**Faster decisions.** Being able to rotate a product, see the options and compare sizes in the browser answers many questions before anyone picks up the phone.

**Competitors already offer it.** Large component suppliers have offered CAD downloads for years. As more manufacturers follow, a catalogue without them looks incomplete.

## What a 3D catalogue includes

- an interactive 3D view in the browser, without installing software
- configuration of key options (sizes, connections, motor, orientation) with the model updating to match
- CAD downloads in common neutral formats, such as STEP, alongside 2D drawings
- the model linked to the same product data as the data sheet and price list, so they always match

## What it takes to get there

The 3D view is the visible part. The real work is underneath:

1. **Clean product data.** Each configurable option needs to be defined as data: which sizes exist, which combinations are allowed, and which dimensions change.
2. **Simplified models.** Manufacturing CAD models are detailed and often confidential. Customer-facing models are simplified to the outer envelope and connection points.
3. **A link between data and geometry.** The configuration chosen in the catalogue needs to select or generate the matching model.

That is why 3D catalogues work best when built on structured [product data](/services/product-data/). If your data already describes your variants clearly, adding 3D is a natural next step. If it does not, the data is where to start.

## Start with your most-specified products

You do not need 3D for the whole range. Start with the products engineers specify most often, typically the standard ranges that appear in plant and machine designs, and add the rest over time.
